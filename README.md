## 🚀 Como Executar Localmente

Como se trata de uma aplicação estática leve e auto-contida, não há dependências de compilação ou gerenciadores de pacotes pesados para rodar:

1. **Abrir diretamente no navegador**:
   - Dê um duplo clique no arquivo `index.html` em qualquer navegador moderno.

2. **Utilizando um servidor local (Recomendado)**:
   ```bash
   # Utilizando Python
   python -m http.server 8000
   
   # Ou utilizando Node.js / npx
   npx serve .
   ```
   Acesse via navegador em: `http://localhost:8000`
